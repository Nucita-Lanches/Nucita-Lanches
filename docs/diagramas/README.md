# Diagramas da solução

Os três diagramas descrevem o domínio previsto no `PROJECT_CONTEXT.md`. Eles não afirmam que
todas as funcionalidades desse modelo já existam no código.

- [`der.puml`](der.puml): modelo conceitual dos dados. O projeto ainda não usa banco relacional;
  o armazenamento atual é em memória.
- [`classes.puml`](classes.puml): classes atuais e relações de domínio previstas, identificadas
  como implementadas, parciais ou planejadas.
- [`casos-de-uso.puml`](casos-de-uso.puml): funcionalidades disponíveis no menu atual e
  funcionalidades descritas no contexto, mas ainda planejadas.

Os arquivos usam PlantUML. Podem ser visualizados no IntelliJ com um plugin PlantUML ou em um
visualizador compatível, sem adicionar dependências ao projeto.
