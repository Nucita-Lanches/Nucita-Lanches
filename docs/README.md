# Nucita Lanches

Sistema acadêmico para organizar pedidos realizados em mesas de uma lanchonete.

## Objetivo

O projeto substitui o controle manual de pedidos por uma aplicação orientada a objetos. A aplicação deverá permitir cadastrar produtos e mesas, abrir pedidos, adicionar itens, calcular valores e finalizar pedidos.

## Estado atual

O projeto está em fase de análise e modelagem. A implementação ainda não deve ser considerada concluída.

As principais classes identificadas são:

- `Produto`;
- `Mesa`;
- `Pedido`;
- `ItemPedido`.
